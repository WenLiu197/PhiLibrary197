数据模型

本库全部类型位于 PhiLibrary197.CloudSave（数据模型）与 PhiLibrary197.LocalSave（本地存档）命名空间。

枚举

Difficulty（难度）

值 名称 说明
0 EZ 简单
1 HD 困难
2 IN 疯狂（Insane）
3 AT 另一种（Another）
4 Legacy 旧谱遗留，仅序列化
5 SP 特殊谱（愚人节等），仅序列化

ScoreStatus（成绩状态）

值 名称 判定
-1 Bugged 异常成绩（acc=100 但非满分等）
0 NotFc 未 FC（仅原始解析用）
1 Fc Full Combo
2 Phi 全 P（acc=100 且分数=1,000,000）
3 Vu 分数 ≥ 960,000
4 S 分数 ≥ 920,000
5 A 分数 ≥ 880,000
6 B 分数 ≥ 820,000
7 C 分数 ≥ 700,000
8 False 分数 < 700,000

ChallengeRank（挑战等级）

值 名称 平均分要求
0 WhiteOrNone 白（无挑战码）
1 Green ≥ 820,000
2 Blue ≥ 900,000
3 Red ≥ 950,000
4 Gold ≥ 980,000
5 Rainbow = 1,000,000

Flags 枚举（按位组合）

枚举 位含义
DifficultyUnlockFlag EZ/HD/IN/AT 各一位
GameKeyFlagType 收藏阅读数 / 单曲解锁 / 收藏解锁数 / 插图 / 头像
RandomVersionFlag Random 各版本（Normal/R/A/N/D/O/M）
SongRecordFlag 各曲目 IN 难度 S 评价记录
Chapter8UnlockFlag 第八章解锁阶段
TakumiUnlockFlag Takumi 曲目 IN S 评价记录

核心数据类

SongScore（单曲成绩）

public class SongScore
{
    public int Score { get; set; }          // 0 ~ 1,000,000
    public float Accuracy { get; set; }     // 0 ~ 100
    public string Id { get; set; }          // 曲目 id，如 "Stasis.Maozon.0"
    public Difficulty Difficulty { get; set; }
    public ScoreStatus Status { get; set; } // 由 Score/Accuracy/FC 自动推导
}

CompleteScore（完整成绩）

见 定数表与 RKS。核心成员：Score、Name / NameOrDefault、ChartConstant、Rks、Default（占位用）。

RawScore（本地存档原始成绩）

public struct RawScore { int Score; float Accuracy; ScoreStatus Status; }
static RawScore FromJson(string json);
SongScore ToSongScore(string songId, Difficulty difficulty);

GameRecord（成绩容器）

public class GameRecord
{
    byte Version;            // 最新 1
    List<SongScore> Records; // 全部成绩
}

RKS 相关方法见 定数表与 RKS。

Summary（游玩统计）

public class Summary
{
    byte SaveVersion;
    int GameVersion;
    float Rks;              // 游戏内显示值（可能不准，建议自行计算）
    Challenge Challenge;    // 挑战码
    string Avatar;          // 头像 id
    PlayCountSummary EZPlayRecord, HDPlayRecord, INPlayRecord, ATPlayRecord;
}

PlayCountSummary：ClearedCount（通关数）、FullComboCount（FC 数）、PhiCount（Phi 数）。

Challenge（挑战码）

public struct Challenge
{
    short RawCode;          // 原始码，如 548
    ChallengeRank Rank;     // 码 / 100
    byte Level;             // 码 % 100
    bool HasEverDone;       // 是否做过挑战
}

Money（货币）

KiB/MiB/GiB/TiB/PiB 五级计数，Money.Zero 空值，支持相等/比较/格式化。

GameProgress（解锁进度）

Version（最新 4）、IsFirstRun、LegacyChapterFinished、GameCompleted、Money、ChallengeModeRank、三魔王曲解锁旗标、Node2 → Node3 → Node4 链式结构（Random 版本、第八章、Takumi 解锁）。

GameSettings / GameUserInfo / GameKey

  • GameSettings：byte Version + 设置字段（详见源码注释）
  • GameUserInfo：byte Version + 用户信息字段
  • GameKey：IList<GameKeyFlag> Flags——用 GameKeyFlag.ReadPayload / WritePayload / RemovePayload 读写各类型载荷

输出模型

ExportScore（Excel 友好）：ID、Name、Difficulty、ChartConstant、Score、Acc、RksGiven、Status。

异常

类型 触发场景
MaxValueArgumentOutOfRangeException 索引越界（如存档索引超范围）
DebugArgumentNullException 内部空引用，ToStringDetailed() 输出完整信息
Warning

DebugArgumentNullException 的详细消息可能含敏感数据，只用于后端/日志排查，不要直接展示给玩家。
