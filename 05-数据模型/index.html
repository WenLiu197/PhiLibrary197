枚举

Difficulty

PhiLibrary197.Scores

值 名称 说明
0 EZ Easy
1 HD Hard
2 IN Insane
3 AT Another
4 Legacy 旧谱，仅用于序列化/查询
5 SP 特殊谱，仅用于序列化/查询

Legacy/SP 没有定数，不参与 RKS。

ScoreStatus

PhiLibrary197.Scores

值 名称 判定
-1 Bugged 异常成绩（例如 acc=100 但不是 1,000,000）
0 NotFc 未 FC，仅用于原始解析
1 Fc Full Combo
2 Phi acc=100 且 score=1,000,000
3 Vu score >= 960,000
4 S score >= 920,000
5 A score >= 880,000
6 B score >= 820,000
7 C score >= 700,000
8 False score < 700,000

SongScore.Status 是计算属性，会根据 Score、Accuracy 和内部 FC 标记重新推导。

成绩模型

SongScore

PhiLibrary197.Scores.SongScore

public class SongScore
{
    public int Score { get; set; }          // 0 ~ 1,000,000
    public float Accuracy { get; set; }     // 0 ~ 100
    public string Id { get; set; }          // 例：Stasis.Maozon.0
    public Difficulty Difficulty { get; set; }
    public ScoreStatus Status { get; }      // 按 Score/Accuracy/FC 推导
}

构造：

using PhiLibrary197.Scores;

SongScore score = new(
    score: 999_000,
    acc: 99.5f,
    id: "Stasis.Maozon.0",
    difficulty: Difficulty.IN,
    status: ScoreStatus.Vu);

CompleteScore

PhiLibrary197.Scores.CompleteScore 是带定数和歌名的成绩视图：

成员 说明
Score SongScore
Name 歌名；缺失抛异常
NameOrDefault 歌名；缺失回退 id
ChartConstant 定数；缺失抛 KeyNotFoundException
Rks 单曲 RKS
Default 占位成绩，用于补齐 Phi 数量

CompleteScore 由 GameRecord.GetCompleteScores 系列方法创建，不要自己用假定数表构造。

ChartConstantKey

public record struct ChartConstantKey(string SongId, Difficulty Difficulty);

SongId 是完整 id，包含数字后缀，例如 Stasis.Maozon.0。

ExportScore

PhiLibrary197.Scores.ExportScore 是 Excel 友好的数据模型，不是导出器：

public class ExportScore
{
    public required string ID { get; set; }
    public required string Name { get; set; }
    public required string Difficulty { get; set; }
    public required float ChartConstant { get; set; }
    public required int Score { get; set; }
    public required double Acc { get; set; }
    public required double RksGiven { get; set; }
    public required string Status { get; set; }
}

库不提供 CSV/TSV/Excel 写入方法；调用方自己把 CompleteScore 映射成 ExportScore 后输出。

RawScore

PhiLibrary197.LocalSave.RawScore

public struct RawScore
{
    public int Score { get; set; }
    public float Accuracy { get; set; }
    public ScoreStatus Status { get; set; }

    public static RawScore FromJson(string json);
    public SongScore ToSongScore(string songId, Difficulty difficulty);

Summary / PlayCountSummary

public class Summary
{
    public byte SaveVersion { get; set; }

Challenge

public struct Challenge
{
    public short RawCode { get; set; }
    public ChallengeRank Rank { get; set; }
    public byte Level { get; set; }
    public bool HasEverDone { get; } // RawCode != 0
}

GameProgress

GameProgress 包含版本、首运行标记、章节完成、货币、挑战等级、三魔王曲解锁，以及 Node2/Node3/Node4 链式扩展数据（Random 版本、第八章、Takumi）。

GameSettings / GameUserInfo / GameKey

  • GameSettings：游戏设置与版本。
  • GameUserInfo：用户信息与版本。
  • GameKey：IList<GameKeyFlag> Flags，通过 GameKeyFlag.ReadPayload/WritePayload/RemovePayload 操作载荷。

异常

类型 场景
ArgumentException 参数非法（token 格式、state 不匹配、路径为空等）
InvalidDataException zip/存档条目损坏或为空
InvalidOperationException 资源缺失、登录被拒绝、未知 QR 状态
TimeoutException 二维码/登录过期
MaxValueArgumentOutOfRangeException 存档索引越界
RequestException 登录请求失败；公开 Failing/HttpStatus
DebugArgumentNullException 内部空引用，带调试信息，不要直接展示给用户
