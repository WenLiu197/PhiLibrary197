登录认证

Phigros 云存档使用 TapTap 账号体系（LeanCloud 后端）。完整链路：

TapTap 授权
  -> TapTapTokenData
  -> TapTapProfileData
  -> LCCombinedAuthData
  -> LCHelper.LoginAndGetToken
  -> LeanCloud session token
  -> new Save(sessionToken)

端点参数

登录 API 的参数是 useChinaEndpoint：

值 含义
true 国服（默认）
false 国际服
Important

这和 new Save(token, isInternational) 相反： Save.isInternational: false 是国服，Save.isInternational: true 是国际服。

所有示例默认国服。国际服请显式传 useChinaEndpoint: false，或运行示例时加 --intl。

方式一：QRCode 扫码登录（推荐）

使用预制 TapTapQrCodeLogin，不用自己写轮询循环：

using PhiLibrary197.Authentication;

TapTapQrCodeLogin login = await TapTapQrCodeLogin.CreateAsync(
    useChinaEndpoint: true);

Console.WriteLine($"请用 TapTap App 扫描: {login.Url}");
Console.WriteLine($"有效期: {login.ExpiresInSeconds}s");

TapTapTokenData token = await login.WaitForTokenAsync();

TapTapProfileData profile = await TapTapHelper.GetProfile(
    token.Data,
    useChinaEndpoint: true);

string sessionToken = await LCHelper.LoginAndGetToken(
    new LCCombinedAuthData(profile.Data, token.Data),
    useChinaEndpoint: true);

Console.WriteLine($"name: {profile.Data.Name}");
Console.WriteLine($"bio: {profile.Data.Bio ?? "(empty)"}");
Console.WriteLine($"sessionToken: {sessionToken}");

WaitForTokenAsync 会自动：

  • 按 TapTap 返回的 Interval 轮询；
  • 处理 slow_down；
  • 根据 ExpiresInSeconds 判断过期；
  • 用户拒绝时抛 InvalidOperationException；
  • 过期时抛 TimeoutException。

如果想自己控制轮询和 UI：

while (true)
{
    TapTapQrCodeResult result = await login.PollAsync();

    Console.WriteLine(result.Status);

    if (result.Status == TapTapQrCodeStatus.Success)
        return result.Token!;

    if (result.Status is TapTapQrCodeStatus.Denied or TapTapQrCodeStatus.Expired)
        throw new InvalidOperationException($"login stopped: {result.Status}");

    await Task.Delay(TimeSpan.FromSeconds(2));
}

TapTapQrCodeStatus：

值 说明
Pending 还没扫码/授权
Waiting 服务端等待用户操作
SlowDown 降低轮询频率
Denied 用户拒绝
Expired 二维码/设备码过期
Success 成功，Token 非空
Unknown 未识别状态

完整示例：LoginExample.cs

dotnet run --project samples/PhiLibrary197.Samples -- qr

方式二：回调 URL 登录

适合桌面应用：库在本机启动一个 localhost 回调服务器，用户在浏览器里完成授权。

using PhiLibrary197.Authentication;

using TapTapCallbackServer server = TapTapHelper.StartCallbackLogin(
    port: 0,              // 0 = 自动选空闲端口
    useChinaEndpoint: true);

Console.WriteLine($"callback: {server.CallbackUrl}");
Console.WriteLine($"打开授权地址: {server.BeginUrl}");

TapTapTokenData token = await server.WaitForTokenAsync();

TapTapProfileData profile = await TapTapHelper.GetProfile(
    token.Data,
    useChinaEndpoint: true);

string sessionToken = await LCHelper.LoginAndGetToken(
    new LCCombinedAuthData(profile.Data, token.Data),
    useChinaEndpoint: true);

特点：

  • 只监听 localhost 的 IPv4/IPv6 回环地址；
  • 不需要 HttpListener 或 Windows URL ACL；
  • 自动校验 OAuth state，拒绝伪造回调；
  • 自动返回简单 HTML 成功/失败页；
  • port: 0 自动选端口，server.Port 可读实际端口。

完整示例：CallbackLoginExample.cs

dotnet run --project samples/PhiLibrary197.Samples -- callback

自定义回调监听器

如果一定要自己实现 HTTP 监听器，使用带 state 校验的重载：

CallbackLoginData login = TapTapHelper.GenerateCallbackLoginUrl(
    "http://localhost:8080/callback",
    useChinaEndpoint: true);

// 你自己的 listener 解析到 code/state 后：
TapTapTokenData token = await TapTapHelper.HandleCallbackLogin(
    login,
    code: codeFromQuery,
    state: stateFromQuery,
    useChinaEndpoint: true);

state 不匹配会抛 ArgumentException。不要调用不校验 state 的旧重载处理不可信回调。

方式三：手动组装凭证

如果已经从其他渠道拿到 TapTap access token 和 profile：

using PhiLibrary197.Authentication;

TapTapProfileData.ProfileData profile = new()
{
    OpenId = "...",
    UnionId = "...",
    Name = "...",
    Avatar = "...",
};

TapTapTokenData.TokenData token = new()
{
    Kid = "...",
    Token = "...",
    TokenType = "mac",
    MacKey = "...",
    MacAlgorithm = "hmac-sha-1",
    Scope = "public_profile",
};

string sessionToken = await LCHelper.LoginAndGetToken(
    new LCCombinedAuthData(profile, token),
    useChinaEndpoint: true);

主要类型

类型 关键成员
TapTapTokenData Data.Kid、Token、TokenType、MacKey、MacAlgorithm、Scope
TapTapProfileData Data.OpenId、UnionId、Name、Gender、Avatar、Bio
CompleteQRCodeData Url、DeviceCode、DeviceID、ExpiresInSeconds、Interval
TapTapQrCodeLogin Url、PollAsync、WaitForTokenAsync
TapTapCallbackServer BeginUrl、CallbackUrl、WaitForCallbackAsync、WaitForTokenAsync
LCCombinedAuthData Kid、Token、MacKey、OpenID、Name、Avatar、UnionID

错误诊断

RequestException 公开：

public RequestException.FailingType Failing { get; }
public HttpStatusCode HttpStatus { get; }

FailingType 包括：

Pending, Denied, Waiting, SlowDown, Expired, None, Unknown

需要区分扫码状态时优先用 CheckQRCodeResultDetailed/PollAsync；RequestException 主要用于请求层异常和自定义登录流程。

常见问题

useChinaEndpoint 到底传什么？

  • 国服：true
  • 国际服：false

Save 的参数相反，注意区分。

QRCode 一直没有结果

WaitForTokenAsync 已经处理轮询；如果没有扫码，会一直等到取消或过期。用 CancellationToken 设置总超时：

using CancellationTokenSource cts = new(TimeSpan.FromMinutes(5));
TapTapTokenData token = await login.WaitForTokenAsync(cts.Token);

回调地址打不开

确认浏览器和程序在同一台机器；localhost 必须指向本机。不要把回调服务器暴露到公网。

sessionToken 和 TapTap token 的区别

  • TapTap token：TapTapTokenData.Data.Token，用于访问 TapTap/LeanCloud 登录接口；
  • session token：LCHelper.LoginAndGetToken 的返回值，25 位，用于 new Save(...)。

不要把两者混用，也不要把 session token 输出到日志或提交到仓库。
