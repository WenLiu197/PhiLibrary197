Phigros 本地存档通常位于 `playerPrefsV2.xml`，成绩以 XML 键值对存储。值不是直接可读文本，需要先 URL 解码，再用 `LocalSave` 解密。

## 数据流

```text
playerPrefsV2.xml
  -> 读取 <string name="..." >value</string>
  -> WebUtility.UrlDecode
  -> LocalSaveApi.DecryptLocalSaveStringNew
  -> 键：songId + ".Record." + difficulty
  -> 值：RawScore JSON
  -> RawScore.ToSongScore
```

## 解密单个字段

```csharp
using System.Net;
using LocalSaveApi = PhiLibrary197.LocalSave.LocalSave;

string urlEncoded = "eSB6QJlXU1vwHjVx7kcpb4%2Fjdk9o5j4Wiatn%2BjrJ%2BetI2KFMlPDyH8s7I8zM%2BqlW";

byte[] cipher = Convert.FromBase64String(WebUtility.UrlDecode(urlEncoded));
string plain = LocalSaveApi.DecryptLocalSaveStringNew(cipher);
```

也可以直接传 Base64 字符串：

```csharp
using LocalSaveApi = PhiLibrary197.LocalSave.LocalSave;
string plain = LocalSaveApi.DecryptLocalSaveStringNew(WebUtility.UrlDecode(urlEncoded));
```

> [!NOTE]
> `LocalSave` 是类名，`PhiLibrary197.LocalSave` 同时也是命名空间。实际写代码时可以用别名避免歧义：
>
> ```csharp
> using LocalSaveApi = PhiLibrary197.LocalSave.LocalSave;
> string plain = LocalSaveApi.DecryptLocalSaveStringNew(...);
> ```

## 解析 RawScore

解密后的值形如：

```json
{"s":992580,"a":99.17559051513672,"c":1}
```

```csharp
using PhiLibrary197.LocalSave;

RawScore raw = RawScore.FromJson(plain);
Console.WriteLine($"score={raw.Score}");
Console.WriteLine($"accuracy={raw.Accuracy}");
Console.WriteLine($"status={raw.Status}");
```

`RawScore`：

| 属性 | JSON 键 | 说明 |
| --- | --- | --- |
| `Score` | `s` | 分数，0 ~ 1,000,000 |
| `Accuracy` | `a` | 准确率，0 ~ 100 |
| `Status` | `c` | 原始状态；FC/Phi 等由后续逻辑推导 |

## 键的格式

解密后的键通常形如：

```text
MARENOL.LeaF.0.Record.HD
```

不要把歌曲 id 固定按 `.` 分成 3 段；更稳妥的方式是找最后一个 `.Record.`：

```csharp
int marker = decryptedKey.LastIndexOf(".Record.", StringComparison.Ordinal);
if (marker < 0) continue;

string songId = decryptedKey[..marker];
string difficultyText = decryptedKey[(marker + ".Record.".Length)..];
```

## 完整可运行示例

下面代码会读取 `playerPrefsV2.xml`，解密所有成绩并打印前 10 条。它对应示例项目里的 [LocalSaveExample.cs](https://github.com/WenLiu197/PhiLibrary197/blob/master/samples/PhiLibrary197.Samples/LocalSaveExample.cs)。

```csharp
using System.Net;
using System.Xml.Linq;
using PhiLibrary197.LocalSave;
using PhiLibrary197.Scores;
using LocalSaveApi = PhiLibrary197.LocalSave.LocalSave;

string path = args.FirstOrDefault()
    ?? Environment.GetEnvironmentVariable("PHIGROS_PREFS_PATH")
    ?? throw new ArgumentException("请传入 playerPrefsV2.xml 路径，或设置 PHIGROS_PREFS_PATH");

XDocument doc = XDocument.Load(path);
List<SongScore> scores = [];

foreach (XElement element in doc.Descendants("string"))
{
    string? rawName = element.Attribute("name")?.Value;
    if (string.IsNullOrEmpty(rawName))
        continue;

    string decryptedName = LocalSaveApi.DecryptLocalSaveStringNew(WebUtility.UrlDecode(rawName));
    int marker = decryptedName.LastIndexOf(".Record.", StringComparison.Ordinal);
    if (marker < 0)
        continue;

    string songId = decryptedName[..marker];
    string difficultyText = decryptedName[(marker + ".Record.".Length)..];
    if (!Enum.TryParse(difficultyText, ignoreCase: true, out Difficulty difficulty))
        continue;

    string decryptedValue = LocalSaveApi.DecryptLocalSaveStringNew(WebUtility.UrlDecode(element.Value));
    RawScore raw = RawScore.FromJson(decryptedValue);
    scores.Add(raw.ToSongScore(songId, difficulty));
}

Console.WriteLine($"records: {scores.Count}");
foreach (SongScore score in scores.Take(10))
{
    Console.WriteLine($"{score.Id} [{score.Difficulty}] {score.Score} {score.Accuracy:F4}% {score.Status}");
}
```

运行：

```bash
dotnet run --project samples/PhiLibrary197.Samples -- local "C:\path\to\playerPrefsV2.xml"
```

## 常见问题

### 解密后仍是乱码

确认输入已经过 URL 解码，并且传入的是 Base64 字节/字符串；不要对明文再解密一次。

### 只解析到一部分成绩

先用 `element.Attribute("name")` 过滤出真正的 `<string>` 项，再判断键中是否包含 `.Record.`。`playerPrefsV2.xml` 还包含设置、用户信息等非成绩项。

### 缺少定数

本地存档只提供 `SongScore`，没有曲目名和定数。用 [SongDatabase](07-SongDatabase.md) 或 [定数表与 RKS](06-定数表与RKS.md) 补充。

### 想直接算 RKS

把解析出的 `List<SongScore>` 放进 `GameRecord`：

```csharp
using PhiLibrary197.Scores;
using PhiLibrary197.Songs;

GameRecord record = new(scores, version: 1);
SongDatabase db = SongDatabase.LoadFromBuiltIn();
var (phis, sorted, rks) = record.GetSortedListForRks(db.ToConstantMap(), db.ToNameMap());
Console.WriteLine($"RKS: {rks:F4}");
```
