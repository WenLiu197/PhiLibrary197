## 环境要求

- **.NET 10**（`net10.0`）
- 可选的 **Native AOT** / 单文件发布环境
- 云存档和登录功能需要网络访问

## 安装

包 ID 是 `PhiLibrary197`：

```bash
dotnet add package PhiLibrary197
```

PowerShell：

```powershell
Install-Package PhiLibrary197
```

或手动编辑项目文件：

```xml
<ItemGroup>
  <PackageReference Include="PhiLibrary197" Version="0.3.0" />
</ItemGroup>
```

> [!NOTE]
> 包 ID 是 `PhiLibrary197`，不是上游的 `PhigrosLibraryCSharp`。命名空间统一为 `PhiLibrary197.*`。

## 验证安装

不需要 token，也不需要任何外部文件：

```csharp
using PhiLibrary197.Scores;
using PhiLibrary197.Songs;
using PhiLibrary197.Tips;

SongDatabase db = SongDatabase.LoadFromBuiltIn();
Console.WriteLine($"songs: {db.Count}");
Console.WriteLine($"IN: {db.GetSong("Glaciaxion.SunsetRay")?.GetConstant(Difficulty.IN)}");
Console.WriteLine(TipProvider.GetTip());
```

输出类似：

```text
songs: 327
IN: 12.6
兄弟！你好强！
```

对应完整示例：

```bash
dotnet run --project samples/PhiLibrary197.Samples -- builtin
```

## 配置项

库默认零配置。以下配置都是可选的，主要用于代理、WASM、自定义网络层和日志。

### 共享 HttpClient

`Save` 实例默认共享一个 `HttpClient`（连接生命周期 2 分钟）。要整体替换：

```csharp
using System.Net;
using PhiLibrary197.CloudSave;

Save.SharedClient = new HttpClient(new SocketsHttpHandler
{
    Proxy = new WebProxy("http://127.0.0.1:7890"),
    UseProxy = true,
});
```

### 按实例拦截请求

```csharp
Save save = new("your-session-token", isInternational: false);

save.RequestHandler = async (s, request, ct) =>
{
    request.Headers.Add("X-Client", "MyApp");
    return await s.SharedClient.SendAsync(request, ct);
};
```

`RequestHandler` 的签名是：

```csharp
Func<Save, HttpRequestMessage, CancellationToken, Task<HttpResponseMessage>>
```

### 自定义 AES

默认实现使用 `System.Security.Cryptography.Aes`（PKCS7 填充）。如果运行环境没有 AES（例如某些 WASM 场景），替换：

```csharp
save.Decryptor = async (key, iv, data, ct) =>
{
    // 返回解密后的明文字节
    return await MyAes.DecryptAsync(key, iv, data, ct);
};

save.Encryptor = async (key, iv, data, ct) =>
{
    // 返回加密后的密文字节
    return await MyAes.EncryptAsync(key, iv, data, ct);
};
```

委托定义：

```csharp
public delegate Task<byte[]> AESCipherFunction(
    byte[] key,
    byte[] iv,
    byte[] data,
    CancellationToken ct = default);
```

### 自定义 MD5

登录 LeanCloud 时会用到 MD5。默认使用 `MD5.HashData`：

```csharp
using PhiLibrary197.Authentication;

LCHelper.GetMD5HashHexString = async (input, ct) =>
{
    return await MyMd5.HexStringAsync(input, ct);
};
```

### TapTap 请求代理

```csharp
TapTapHelper.Proxy = (client, request) =>
{
    // 可以改请求、换代理，或直接返回自定义响应
    return client.SendAsync(request, CancellationToken.None);
};
```

### HttpClient 和取消

所有网络方法都支持 `CancellationToken`。建议在 UI 或服务层传入超时 token：

```csharp
using PhiLibrary197.CloudSave;
using PhiLibrary197.CloudSave.HttpModels;

using CancellationTokenSource cts = new(TimeSpan.FromSeconds(30));
SaveInfoContainer saves = await save.GetSaveInfoFromCloudAsync(ct: cts.Token);
```

## Native AOT

项目已标记 `IsAotCompatible`，JSON 全部走源生成器。应用发布时：

```xml
<PropertyGroup>
  <PublishAot>true</PublishAot>
</PropertyGroup>
```

```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishAot=true
```

单文件 + trim：

```bash
dotnet publish -c Release -r win-x64 `
  -p:PublishSingleFile=true `
  -p:SelfContained=true `
  -p:PublishTrimmed=true
```

库内置的曲目数据和 Tips 都是嵌入资源，不依赖当前工作目录；AOT/单文件不会因为找文件失败。

详见 [序列化与 AOT](08-序列化与AOT.md)。
