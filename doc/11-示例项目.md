仓库里有一个可直接运行的示例项目：

```text
samples/PhiLibrary197.Samples/
```

它引用本地 `PhiLibrary197` 项目，覆盖内置数据、本地存档、云存档、QRCode 登录、回调登录和源生成 JSON。文档里的完整示例基本都对应这里的真实代码。

## 运行

```bash
dotnet run --project samples/PhiLibrary197.Samples -- help
```

输出：

```text
PhiLibrary197 samples
  dotnet run --project samples/PhiLibrary197.Samples -- builtin
  dotnet run --project samples/PhiLibrary197.Samples -- local <playerPrefsV2.xml>
  set PHIGROS_SESSION_TOKEN=... && dotnet run ... -- cloud
  dotnet run ... -- qr [--intl]
  dotnet run ... -- callback [--intl]
  dotnet run ... -- json
```

## builtin：不需要任何凭证

```bash
dotnet run --project samples/PhiLibrary197.Samples -- builtin
```

演示：

- `SongDatabase.LoadFromBuiltIn()`
- 327 首曲目数量与数据版本
- 按 id 查询、谱师、定数
- Random 变体 `BaseId`/`IsVariant`
- `FindByFullName`
- 合成成绩的 B30/RKS
- `TipProvider.GetTip()`

代码：[BuiltInExample.cs](https://github.com/WenLiu197/PhiLibrary197/blob/master/samples/PhiLibrary197.Samples/BuiltInExample.cs)

## local：解析本地存档

```bash
dotnet run --project samples/PhiLibrary197.Samples -- local "C:\path\to\playerPrefsV2.xml"
```

或：

```bash
set PHIGROS_PREFS_PATH=C:\path\to\playerPrefsV2.xml
dotnet run --project samples/PhiLibrary197.Samples -- local
```

代码：[LocalSaveExample.cs](https://github.com/WenLiu197/PhiLibrary197/blob/master/samples/PhiLibrary197.Samples/LocalSaveExample.cs)

详细说明：[本地存档](02-本地存档.md)

## cloud：读取云存档并算 RKS

需要 LeanCloud session token（25 位），不是 TapTap access token。

```bash
set PHIGROS_SESSION_TOKEN=your-session-token
dotnet run --project samples/PhiLibrary197.Samples -- cloud
```

国际服：

```bash
set PHIGROS_INTERNATIONAL=1
dotnet run --project samples/PhiLibrary197.Samples -- cloud
```

代码：[CloudSaveExample.cs](https://github.com/WenLiu197/PhiLibrary197/blob/master/samples/PhiLibrary197.Samples/CloudSaveExample.cs)

演示：查询存档、按索引读取、`Summary`、`GameRecord`、内置定数、B30/RKS。

详细说明：[云存档](03-云存档.md)

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `PHIGROS_SESSION_TOKEN` | `cloud` 示例使用的 LeanCloud session token |
| `PHIGROS_INTERNATIONAL` | `1`/`true` 时走国际服 |
| `PHIGROS_PREFS_PATH` | `local` 示例的 `playerPrefsV2.xml` 路径 |

示例程序不会把 token 写到文件或仓库。运行日志会打印 session token，请不要把日志公开。

## 把示例复制到自己的项目

1. 新建 `net10.0` 控制台项目；
2. 添加 `<PackageReference Include="PhiLibrary197" Version="0.3.0" />`；
3. 复制对应 `.cs` 的 `using` 和逻辑；
4. 把 `samples/PhiLibrary197.Samples` 的项目引用改成 NuGet 包引用。

示例项目本身使用 `ProjectReference`，方便在仓库内调试；发布给用户时用 NuGet 即可。
