`Save` 类封装了 Phigros 云存档（LeanCloud）的完整访问流程。

## 创建 Save

```csharp
using PhiLibrary197.CloudSave;

Save save = new("你的25位token", isInternational: false);
```

| 参数 | 说明 |
| --- | --- |
| `sessionToken` | 25 位字母数字 token，先经 `IsSemanticallyValidToken` 格式校验，非法抛 `ArgumentException` |
| `isInternational` | `false` = 国服，`true` = 国际服 |

服务器地址常量：

```csharp
Save.CloudServerAddress;              // 国服地址
Save.InternationalCloudServerAddress; // 国际服地址
Save.GetCloudServerAddress(true);     // 按参数选择
```

## 查询存档列表

```csharp
SaveInfoContainer container = await save.GetSaveInfoFromCloudAsync();
foreach (SaveInfo info in container.Results)
    Console.WriteLine($"{info.Name} | {info.UpdatedAt} | {info.GameFile?.Url}");

// 自定义查询参数
var filtered = await save.GetSaveInfoFromCloudAsync(
    [new("limit", "10"), new("skip", "5")]);
```

> [!NOTE]
> `SaveInfo.GameFile` 可能为 `null`（上游 v5 起的可空行为），访问其成员前请判空。

## 下载并解密存档

```csharp
// 方式一：按索引（0 = 最新）
SaveContext ctx = await save.GetSaveContextAsync(0);

// 方式二：指定 SaveInfo
SaveContext ctx2 = await save.GetSaveContextAsync(container.Results[0]);

// 方式三：手动拿 zip 字节再解密
byte[] zip = await save.GetSaveZipAsync(target.GameFile!);
SaveContext ctx3 = await SaveContext.FromZipAsync(zip, target, save.Decrypt);
```

## 读取数据

```csharp
var summary  = ctx.ReadSummary();      // 游玩统计（含挑战码）
var record   = ctx.ReadGameRecord();   // 全部成绩
var settings = ctx.ReadGameSettings(); // 游戏设置
var progress = ctx.ReadGameProgress(); // 解锁进度
var gameKey  = ctx.ReadGameKey();      // Key 数据
var userInfo = ctx.ReadGameUserInfo(); // 用户信息
```

## 修改并回写

```csharp
var progress = ctx.ReadGameProgress();
// ...修改字段...
ctx.SaveGameProgress(progress);

ctx.SaveGameRecord(record);
ctx.SaveGameSettings(settings);
ctx.SaveGameKey(gameKey);
ctx.SaveGameUserInfo(userInfo);
ctx.SaveSummary(summary);
```

加密回写为 zip：

```csharp
using System.IO.Compression;

using MemoryStream ms = new();
await ctx.SaveToStreamAsync(ms, save.Encrypt);
byte[] newZip = ms.ToArray();
```

> [!WARNING]
> 库支持保存到本地文件，但**不支持上传回云**（上游接口限制）。

## 用户信息

```csharp
PlayerInfo me = await save.GetPlayerInfoAsync();
Console.WriteLine($"昵称: {me.NickName ?? "guest"} | 用户名: {me.UserName}");

string uid = await save.GetUserObjectId(); // objectId 会被缓存
```

## 完整示例：读取成绩用于 RKS 计算

```csharp
Save save = new(token, isInternational: false);
SaveContext ctx = await save.GetSaveContextAsync(0);
GameRecord record = ctx.ReadGameRecord();

// 定数表与歌名表加载，见 [定数表与 RKS](06-定数表与RKS.md)
var constantMap = ScoreHelper.LoadConstantTable("difficulty.tsv");
var nameMap     = ScoreHelper.LoadSongInfo("info.tsv");
var (phis, other, rks) = record.GetSortedListForRks(constantMap, nameMap);
```

## WASM 注意事项

- 替换 `save.Decryptor` / `save.Encryptor`（浏览器无 AES）
- 替换 `LCHelper.GetMD5HashHexString`
- 必要时设置 `TapTapHelper.Proxy` / `Save.RequestHandler` 处理 CORS
