本页记录面向用户的版本变化。完整的包发布说明和更早的上游版本记录见 [CHANGELOG.MD](https://github.com/WenLiu197/PhiLibrary197/blob/master/CHANGELOG.MD)。

## 1.0.0

> 2026-10-25

这是 API 大改后的第一个正式版本，**包含破坏性变更**。

### 命名空间重构

| 旧 | 新 |
| --- | --- |
| `PhiLibrary197.CloudSave.Login` | `PhiLibrary197.Authentication` |
| 成绩模型（`GameRecord`、`SongScore` 等） | `PhiLibrary197.Scores` |
| `SongDatabase` / `SongEntry` | `PhiLibrary197.Songs` |
| 无 | 新增 `PhiLibrary197.Tips` |

升级时需要同步修改 `using`、类型名和方法名。

### 内置数据

- 新增 `SongDatabase.LoadFromBuiltIn()`：内置 **327 首**曲目的定数、曲名、曲师、画师、谱师
- 内置数据版本：`2026.10.24`
- 新增 `SongEntry.BaseId` / `IsVariant`，统一 Random 等数字版本变体
- 新增 `TipProvider.GetTip()`：191 条简体中文 Tips

### 输入与查询

- `SongDatabase.LoadFromFile` 新增 `TextReader` / `Stream` 重载
- `ScoreHelper.LoadConstantTable` / `LoadSongInfo` 新增 `TextReader` / `Stream` 重载
- `FindByName` 重命名为 `FindByFullName`
- `Load(...)` 标记为过时，改用 `LoadFromFile(...)`

### 登录认证

- 新增 `TapTapQrCodeLogin` 自动轮询
- 新增 `TapTapQrCodeStatus` / `TapTapQrCodeResult`
- 新增 `TapTapCallbackServer` / `TapTapHelper.StartCallbackLogin`
- `HandleCallbackLogin` 新增校验 OAuth `state` 的重载
- `RequestException` 公开 `Failing` / `HttpStatus`
- 新增 `SlowDown` / `Expired` 登录状态
- `TapTapProfileData.ProfileData` 新增可选 `Bio`

### 云存档与本地存档

- `SaveContext` 新增无 `SaveInfo` 的 zip 构造重载
- `SimplifiedSaveInfo` 新增 `Name` / `ObjectId`
- `SaveInfoContainer.Results` 默认空列表
- 本地存档示例改用最后一个 `.Record.` 拆分歌曲 id 和难度

### 文档与示例

- 重写全部主题文档，修正旧命名空间和参数方向
- 新增 [示例项目](11-示例项目.md)
- 删除重构前的逐类 API 页面，API 速查集中到 [API 参考](10-API参考.md)
- 发布 workflow 的 .NET SDK 从 10.0 对齐到 11.0 preview

## 0.2.0
