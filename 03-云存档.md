`PhiLibrary197.CloudSave.Save` 封装 Phigros 云存档（LeanCloud）的查询、下载、解密、读取和本地回写。**库不支持把修改后的存档上传回云端**，只支持导出 zip。

## 先获取 session token

云存档使用 LeanCloud session token，不是 TapTap access token。没有 token 时先看 [登录认证](04-登录认证.md)。

```csharp
using PhiLibrary197.CloudSave;

using Save save = new("your-25-char-session-token", isInternational: false);
```

| 参数 | 说明 |
| --- | --- |
| `sessionToken` | 25 位 ASCII 字母/数字；格式非法会抛 `ArgumentException` |
| `isInternational` | `false` = 国服，`true` = 国际服 |

> [!IMPORTANT]
> `Save.isInternational` 与登录 API 的 `useChinaEndpoint` 参数方向相反：
> `isInternational: false` 对应国服；`useChinaEndpoint: true` 对应国服。

## 查询存档列表

```csharp
using PhiLibrary197.CloudSave;
using PhiLibrary197.CloudSave.HttpModels;

using Save save = new(token, isInternational: false);
SaveInfoContainer container = await save.GetSaveInfoFromCloudAsync();

Console.WriteLine($"saves: {container.Results.Count}");
foreach (SaveInfo info in container.Results)
{
    Console.WriteLine($"{info.Name} | {info.UpdatedAt:u}");
    Console.WriteLine($"  game file: {info.GameFile?.Url ?? "(missing)"}");
}
```

`container.Results` 默认是空列表，不会因为缺少 `results` 字段而为 `null`。`SaveInfo.GameFile` 仍可能为 `null`，访问前判空。

自定义查询参数：

```csharp
var queries = new List<KeyValuePair<string, string>>
{
    new("limit", "10"),
    new("skip", "0"),
};

SaveInfoContainer page = await save.GetSaveInfoFromCloudAsync(queries);
```

## 下载并解密

### 按索引

```csharp
SaveContext context = await save.GetSaveContextAsync(index: 0);
```

索引 `0` 是最新存档；越界抛 `MaxValueArgumentOutOfRangeException`。

### 按 SaveInfo

```csharp
SaveInfo info = container.Results[0];
SaveContext context = await save.GetSaveContextAsync(info);
```

### 手动下载 zip

```csharp
SaveInfo info = container.Results[0];
SimplifiedSaveInfo simplified = info.Simplify();

byte[] zip = await save.GetSaveZipAsync(simplified);
SaveContext context = await SaveContext.FromZipAsync(zip, info, save.Decrypt);
```

如果只有 zip、没有 `SaveInfo`（例如本地保存的旧 zip）：

```csharp
byte[] zip = await File.ReadAllBytesAsync("save.zip");
SaveContext context = await SaveContext.FromZipAsync(zip, save.Decrypt);
```

这种重载没有原始 summary，`ReadSummary()` 不可用，但 `ReadGameRecord()`、`ReadGameSettings()`、`ReadGameProgress()` 等可以正常读取。

## 读取内容

```csharp
Summary summary = context.ReadSummary();
GameRecord record = context.ReadGameRecord();
GameSettings settings = context.ReadGameSettings();
GameProgress progress = context.ReadGameProgress();
GameKey gameKey = context.ReadGameKey();
GameUserInfo userInfo = context.ReadGameUserInfo();
```

| 方法 | 返回 | 说明 |
| --- | --- | --- |
| `ReadSummary()` | `Summary` | 游戏内统计、挑战码、显示 RKS |
| `ReadGameRecord()` | `GameRecord` | 全部成绩 |
| `ReadGameSettings()` | `GameSettings` | 游戏设置 |
| `ReadGameProgress()` | `GameProgress` | 解锁进度 |
| `ReadGameKey()` | `GameKey` | Key 数据 |
| `ReadGameUserInfo()` | `GameUserInfo` | 用户信息 |

读取成绩并计算 RKS：

```csharp
using PhiLibrary197.Scores;
using PhiLibrary197.Songs;

SongDatabase db = SongDatabase.LoadFromBuiltIn();
GameRecord record = context.ReadGameRecord();

var (phis, sorted, rks) = record.GetSortedListForRks(db.ToConstantMap(), db.ToNameMap());
Console.WriteLine($"RKS: {rks:F4}");

foreach (CompleteScore score in sorted.Take(10))
    Console.WriteLine($"{score.NameOrDefault} [{score.Score.Difficulty}] {score.Rks:F4}");
```

## 修改并回写 zip

`SaveContext` 的 `Save...` 方法只修改内存中的条目；需要再调用 `SaveToStreamAsync` 才会得到新的加密 zip。

```csharp
GameProgress progress = context.ReadGameProgress();
// 修改 progress 的字段...
context.SaveGameProgress(progress);

GameRecord record = context.ReadGameRecord();
context.SaveGameRecord(record);

using MemoryStream output = new();
await context.SaveToStreamAsync(output, save.Encrypt);
byte[] newZip = output.ToArray();
await File.WriteAllBytesAsync("modified-save.zip", newZip);
```

也可以写入 `ZipArchive`：

```csharp
using System.IO.Compression;

using FileStream file = File.Create("modified-save.zip");
using ZipArchive archive = new(file, ZipArchiveMode.Create);
await context.SaveToZipAsync(archive, save.Encrypt);
```

> [!WARNING]
> 修改后的 zip 不会自动上传。请自行确认目标平台/接口是否允许上传，并承担修改存档的风险。

## 完整可运行示例

完整代码：[CloudSaveExample.cs](https://github.com/WenLiu197/PhiLibrary197/blob/master/samples/PhiLibrary197.Samples/CloudSaveExample.cs)

```csharp
using PhiLibrary197.CloudSave;
using PhiLibrary197.CloudSave.HttpModels;
using PhiLibrary197.Scores;
using PhiLibrary197.Songs;

string token = Environment.GetEnvironmentVariable("PHIGROS_SESSION_TOKEN")
    ?? throw new InvalidOperationException("set PHIGROS_SESSION_TOKEN");

bool international = Environment.GetEnvironmentVariable("PHIGROS_INTERNATIONAL") is "1" or "true";
using Save save = new(token, isInternational: international);

SaveInfoContainer container = await save.GetSaveInfoFromCloudAsync();
Console.WriteLine($"saves: {container.Results.Count}");
if (container.Results.Count == 0)
    return;

SaveContext context = await save.GetSaveContextAsync(0);
Summary summary = context.ReadSummary();
GameRecord record = context.ReadGameRecord();

SongDatabase db = SongDatabase.LoadFromBuiltIn();
var (phis, sorted, rks) = record.GetSortedListForRks(db.ToConstantMap(), db.ToNameMap());

Console.WriteLine($"game version: {summary.GameVersion}");
Console.WriteLine($"summary rks: {summary.Rks:F6}");
Console.WriteLine($"computed rks: {rks:F6}");
Console.WriteLine($"records: {record.Records.Count}, complete: {sorted.Count}, phis: {phis.Count}");

foreach (CompleteScore score in sorted.Take(10))
    Console.WriteLine($"{score.NameOrDefault} [{score.Score.Difficulty}] {score.Score.Score} {score.Rks:F4}");
```

运行：

```bash
set PHIGROS_SESSION_TOKEN=your-token
dotnet run --project samples/PhiLibrary197.Samples -- cloud
```

国际服再加：

```bash
set PHIGROS_INTERNATIONAL=1
```

## 常见问题

### token 格式错误

`Save` 构造函数只接受 25 位 ASCII 字母/数字。TapTap access token 不是 LeanCloud session token，不能直接传。

### `GameFile` 为 null

部分存档元数据缺少 `gameFile`。列表展示时判空；下载时使用 `GetSaveContextAsync(index)` 或自行处理缺失。

### 读取 summary 抛异常

如果使用不带 `SaveInfo` 的 `FromZipAsync` 重载，`RawSummary` 为空，`ReadSummary()` 不可用；改用 `ReadGameRecord()` 等条目。

### 修改后没有生效

`SaveGameRecord` 等只改内存。必须调用 `SaveToStreamAsync`/`SaveToZipAsync` 生成新 zip；库不上传云端。
